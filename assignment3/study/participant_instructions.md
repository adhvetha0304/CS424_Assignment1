# Assignment 3: Visualization Evaluation

## Participant Instructions

Thank you for taking part in this study!

This study compares two versions of a visualization showing how many people were observed in different shared spaces across seven sessions.

- **Static version:** A heatmap with a table showing the observation details.
- **Interactive version:** The same heatmap, with options to click on cells and highlight sessions based on space and noise level.

The goal is to see whether the interactive features make it easier or faster to answer questions. There are no expectations about how well you should perform.

Participation is voluntary, and you can stop at any time.

## Before Starting

- Use a laptop if possible. If you're using a phone, turn it sideways to view the chart.
- Use the same device for all four questions.
- You can scroll through the visualization as needed.
- Let me know if anything isn't loading or displaying properly.

## Practice (Not Timed)

Before the actual questions, you'll get to try both versions using a small practice dataset. This data is fictional and is not part of the actual study.

**Static practice:**

https://adhvetha0304.github.io/CS424_Assignment1/assignment3/visualization/practice_static.html

Look at the heatmap and the table below it to see how the information is displayed.

**Interactive practice:**

https://adhvetha0304.github.io/CS424_Assignment1/assignment3/visualization/practice_interactive.html

Try the following:

1. Click a cell to see its details.
2. Double-click to clear the selection.
3. Select **Gym** and **Quiet** to highlight matching sessions.
4. Click **Clear Highlight** to reset the chart.

You can ask questions about using either version during practice.

## Study Questions

You'll answer **four questions in total**, two using each version.

For each question:

1. Open the visualization link I provide.
2. Wait for the page to load and let me know when you're ready.
3. I'll show you the question and start the timer.
4. Find the answer using the visualization and tell me your final answer.

Each question has a **120-second time limit**. If you don't finish within that time, the task will be recorded as timed out.

Please don't discuss the correct answers until you've finished all four questions.

## After the Study

I'll ask about your familiarity with charts and whether you had any technical issues.

Your answers, completion times, and device type will be recorded using a participant ID instead of your name. The results will be used to compare the two visualizations.

Thank you for helping with this project!
